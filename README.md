# Laboratorio de Infraestructura y Soporte Técnico

## 📌 Descripción del Proyecto:
Este repositorio contiene la documentación completa, scripts y procedimientos estándar (SOPs) de un entorno de infraestructura híbrida corporativa simulada desde cero. El objetivo es emular el ecosistema tecnológico de una empresa moderna, conectando sistemas locales (on-premises) con servicios en la nube.

## 🛠️ Tecnologías y Herramientas
* **Virtualización:** VMware Workstation Pro
* **Sistemas Operativos:** Windows Server 2022, Windows 11 Pro, Ubuntu Server
* **Automatización:** Python (Librería Faker) y PowerShell
* **Gestión de Servicios (ITSM):** GLPI Help Desk
* **Redes y Conectividad:** Redes NAT, VPN Mesh (Tailscale/ZeroTier)
* **Plataforma Cloud:** Microsoft Entra ID (Azure AD) y Microsoft 365

---
*Nota: Este proyecto está dividido en 4 fases modulares que se construyen de forma secuencial.*
